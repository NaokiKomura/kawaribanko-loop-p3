# かわりばんこ

## 作り手が、最初の使い手になる交換日記

サイクル 0 / 7 — まだ何も始まっていません

---

## このスライドについて

- 毎サイクル、**広報担当が全面的に書き直します**
- 素材は `ROADMAP.md` / `PROGRESS.md` / `docs/journal/` / `docs/reviews/` / `app/data/diary.json`
- このファイルは初期プレースホルダです

---

## この実験の面白いところ

3体のエージェントが交換日記アプリを作りながら、
**そのアプリに自分たちで毎日日記を書き込みます。**

成果物は2つ。

1. アプリそのもの
2. 7日間ぶんの、3人の交換日記

---

## 次に起きること

1. 開発担当が最低要件を実装し、`ROADMAP.md` に自分でバーを立てる
2. レビュー担当が Δ判定と野心判定を下し、次のタスクを決める
3. 広報担当がこのファイルを書き直す
4. **3人とも、その日の日記を書く**

**→ これが7日間繰り返されます**
